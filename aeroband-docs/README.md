# Corda — a practice studio built on the AeroBand AG01
### Feature documentation and product insights for the AeroBand team

> **Independent project, not affiliated with AeroBand.** Corda is a web app (HTML, CSS and JavaScript, no framework, no build step) written by an AG01 owner to explore what a *practice-first* experience could look like when it is fed by the data the AG01 already sends over Bluetooth MIDI. This folder documents every feature of the app (except the song-import / tablature section, which is out of scope here) with screenshots, the exact rules behind each behaviour, and concrete ideas that might be useful for the native app.

## Conventions used in these pages

- **The app's interface is in Brazilian Portuguese.** Every label that appears in a screenshot is quoted in Portuguese followed by an English gloss, e.g. *"Montagem de acorde" (Chord assembly)*.
- Each feature section follows the same shape: **Purpose → How it works → What you see → Exact rules & numbers → Edge cases & limitations → Ideas for the native app.**
- Three labels are used for every claim about the guitar or about accuracy:
  - **Verified** — observed in live captures from a real AG01 (passive, read-only listening).
  - **Inferred** — deduced by the app from verified data (for example, strum direction from the order in which strings arrive).
  - **Simulated** — produced by emulated events for the screenshots or the automated tests.
- **All screenshots are simulated.** They were produced by a headless Chrome driving the app with emulated guitar events and **demonstration data** (19 generated practice sessions), so that every state can be shown without a guitar attached. No personal data appears in them.
- Times are in milliseconds (ms) unless stated; BPM is quarter-note beats per minute; "slot" means one subdivision of a beat.

## Safety statement

The app only **listens** to the guitar. It never writes characteristics, never sends SysEx, never touches firmware, memory or internal calibration, and does not use undocumented commands. This is enforced by an automated test that scans the source for any write call (`tests/safety.test.mjs`) and was mutation-tested (injecting a write makes the test fail). Details in [01](01-ag01-integration.md#safety).

## Run it yourself

```
git clone https://github.com/josiassxz/cordas
cd cordas
./serve.sh            # serves the folder at http://localhost:8731
```
Open it in **Google Chrome** (Web Bluetooth is required to talk to the guitar), or use the *"Experimentar sem guitarra" (Try without a guitar)* demo mode. A hosted copy is also available at <https://josiassxz.github.io/cordas/>.

The screenshots in `images/` were generated by `tools/capture-docs.mjs`, so they can be regenerated at any time.
